## 修复"聊了出差报销却没沉淀任何画像" —— 归纳窗口陈旧兜底

用户追问："不要补充画像，而是要为什么没有沉淀，这是问题"。
（前几轮我误判为"设计如此"，用户纠正——确实是 bug。）

排查：画像沉淀有两条链路
1. 单句抽取 extract_with_llm：实测"分析这个文件+报销表文件名"、"我下周去北京出差"都返回空
   —— prompt 只记长期稳定信息，出差是一次性事件，且附件名在 strip_attachments 时被剥离。
2. 跨轮归纳 digest：手动把报销会话 4 轮喂给 digest()，能产出 1 条
   "以后有报销时，希望按此前确认的格式输出报销文件" —— 归纳机制本身是通的。

**真正根因**：DigestWindow 攒满 6 轮才 add 触发归纳，flush() 只在 reset() 调用。
报销会话实际只有 3 轮进窗口（第4轮"记住这个方式"走 has_explicit_remember 分支直接
record_turn、不进窗口），永远不满 6；用户也不点 reset → 3 轮烂在内存窗口里，
从没被归纳。日志里从无 digest/归纳记录，画像表 11-20 一整天零新增，印证。

修：
- DigestWindow 加 _last_add_at + take_stale(max_idle_s)：距最后 add 超阈值就交出整批归纳
  （语义同 flush，不留尾）。不改变 add 攒批行为，只兜住短会话。
- agent._maybe_persist_profile 每轮开头先 take_stale(profile_digest_idle_s())，
  陈旧批次先归纳，再走原 explicit/攒窗逻辑；复用 win 变量。
- session_config 加 PROFILE_DIGEST_IDLE_S=15*60 + profile_digest_idle_s()。
- 验证：手动 digest 确实能产出画像（已清理测试污染记录）；4 个测试；
  1211 passed（唯一失败既有 test_mcp_source 时序）；ruff/棘轮 360 全绿；后端重启。

**重要边界（要跟用户讲清）**：修了链路 bug ≠ 能推断出"出差"画像。
digest 和单句抽取都禁止从单据推断（docs/13 明确 strip_attachments），
实测 digest 从报销对话归纳出的是"报销按格式输出"，没有"出差"。
要不要让系统从报销单推断"用户会出差"是产品决策，不是 bug 修复范围。

踩坑：测试里 monkeypatch time.monotonic 会干扰 pytest 自身计时，测试从 3s 变 174s。
改成直接改 window._last_add_at 字段。

## 修复对话区不滚动（整页拉到底才能看消息）

用户："对话显示为什么不是滚动的，要把网页拉到最下面才能看完所有对话"。
根因：经典 flexbox `min-height:auto` 陷阱。纵向 flex 子项默认 min-height=内容高度，
不会被压缩 → `.messages` 的 overflow-y:auto 永远不生效，200 条消息把整页撑到 10520px。
链条：.app-container(100vh) → .main-content(flex:1) → .chat-area(flex:1) → .messages(flex:1+overflow)。

修：给链上每个 flex 子项加 `min-height:0`：
- App.vue: .main-content、.sidebar-content 加 min-height:0；.app-container 加 box-sizing:border-box
- ChatPanel.vue: .chat-area、.messages 加 min-height:0

验证（Chrome headless 实测 DOM）：修复前 body 溢出 10036px、内部滚动 false；
修复后 body 无溢出、.messages 内部滚动 true（mScroll=10432 / mClient=380）。
测试用临时 scroll_test.html 已删除。前端 build 通过。

## 隐藏滚动条但保留滚动

用户："滚动条隐藏起来，但要实现滚动效果"。
做法：对 .messages(ChatPanel.vue) 和 .sidebar-content(App.vue) 加跨浏览器三件套：
`scrollbar-width:none`(FF) + `-ms-overflow-style:none`(旧Edge/IE) + `::-webkit-scrollbar{display:none}`(Chrome/Safari)。
不影响 overflow-y:auto，滚轮/触摸/键盘滚动照常。项目原来 .sidebar-tabs 已有同样写法，复用模式。
App.vue 样式非 scoped，伪元素可直接写；ChatPanel.vue 是 scoped，写在组件内即可作用于自身元素。
验证：build 通过，dist CSS 里三处隐藏规则齐全。
